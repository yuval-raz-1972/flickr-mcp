# flickr-mcp

An MCP server that gives AI assistants authenticated access to your Flickr photo library. Add tags, write descriptions, and set titles — all generated by AI, applied to your photos.

Works with any MCP-compatible AI client: Claude, Cursor, Windsurf, and others.

---

## What it does

Once connected, you can ask your AI assistant things like:

- *"Tag all the photos in my Japan album"*
- *"Write a description for this photo"* (with a Flickr URL)
- *"Find my black and white photos and add a 'monochrome' tag"*
- *"Look at my recent uploads and add relevant tags to each one"*

The AI will look at your photos, generate appropriate metadata, and show you a preview before making any changes. You confirm, then it applies them.

---

## Requirements

- Node.js 18 or later
- A free Flickr account
- An MCP-compatible AI client

---

## Setup

### 1. Register a Flickr API key

Go to [flickr.com/services/apps/create/noncommercial](https://www.flickr.com/services/apps/create/noncommercial) and fill out the short form — any app name works, select "personal use." It takes about two minutes. Copy the **API key** and **API secret** from the next page.

### 2. Run the setup command

```bash
npx flickr-mcp setup
```

This will prompt for your API key and secret, open Flickr's authorization page in your browser, and ask you to paste the verification code Flickr shows you. Your credentials are saved to `~/.config/flickr-mcp/credentials.json` and never leave your machine.

### 3. Add flickr-mcp to your AI client

The easiest way is to just ask your AI assistant directly:

> *"Add an MCP server called flickr to my config. The command is* `npx flickr-mcp`*."*

Your assistant knows where its own config file lives and can add the entry for you. Restart the client after it makes the change.

<details>
<summary>Prefer to do it manually?</summary>

The config entry looks like this for most clients:

```json
{
  "mcpServers": {
    "flickr": {
      "command": "npx",
      "args": ["flickr-mcp"]
    }
  }
}
```

**Claude Code** — add to `~/.claude/settings.json` (global) or `.claude/settings.json` in a project.

**Claude Desktop**
- Mac: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

**Cursor / Windsurf** — check your client's MCP settings panel.

</details>

## Available tools

These are the tools your AI assistant can call once the server is running. You don't interact with them directly — just describe what you want in plain language.

| Tool | Description |
|---|---|
| `flickr_list_photos` | List your photostream |
| `flickr_get_photo` | Get full details for a photo, optionally including the image itself for visual analysis |
| `flickr_get_exif` | Read camera metadata — make, model, lens, GPS, shutter speed, ISO |
| `flickr_search_my_photos` | Search your own photos by keyword or tag |
| `flickr_get_albums` | List your albums |
| `flickr_get_album_photos` | List photos inside an album |
| `flickr_add_tags` | Add tags to a photo |
| `flickr_remove_tag` | Remove a tag from a photo |
| `flickr_set_metadata` | Set a photo's title and/or description |

All write operations show a preview before applying — your AI will confirm with you before touching anything.

---

## Privacy and scope

This server can only access **your own photos**. It has no ability to read, search, or modify other users' content. The write access it requests is limited to your account.

Your API credentials are stored locally at `~/.config/flickr-mcp/credentials.json` and are never sent anywhere except Flickr's own API.

## Running from source

```bash
git clone https://github.com/MK3Core/flickr-mcp
cd flickr-mcp
npm install
npm run build
node dist/index.js setup
```

Then point your MCP client at `node /path/to/flickr-mcp/dist/index.js` instead of `npx flickr-mcp`.
